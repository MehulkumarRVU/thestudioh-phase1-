# TheStudioH — Phase 1

Lightweight frontend scaffold for TheStudioH project (Vite + React + TypeScript).

## Quick start

Prerequisites: Node.js (16+), and one of `pnpm`, `npm`, or `yarn`.

- Install dependencies (recommended: `pnpm`):

```bash
pnpm install
# or
npm install
# or
yarn install
```

- Run the development server:

```bash
pnpm dev
# or
npm run dev
# or
yarn dev
```

- Build for production:

```bash
pnpm build
# or
npm run build
# or
yarn build
```

## Repository

This repo was pushed from a local workspace. Main tools: Vite, Tailwind, Radix UI components and MUI icons.
